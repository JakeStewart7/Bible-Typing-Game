# Repository agent instructions

All coding agents working in this repository must read and follow
`docs/CODING_STANDARDS.md` before changing code.

Treat those standards as implementation requirements. Before completing work,
run the smallest existing checks that cover the change.

Commit verified work frequently:

- Make a focused milestone commit after each independently useful fix, feature,
  or refactor.
- Do not wait until a long session ends to commit several unrelated changes.
- Keep commits buildable, reviewable, and safe to revert.
- Do not commit partial or failing work solely to create a checkpoint.
- Never amend, squash, force-push, or include unrelated user changes without
  explicit approval.
